# Independent numerical verification (indep-)

Status: numerical evidence only (floating point, not interval-certified). Not a proof. Written by an independent verifier; geometry code written from the spec before `circle_research.py` was read.

## What was run
- `independent/geom.py` (sha256 7212846e...): exact angular-measure integrator. Per segment, the covered set at radius r is the union of the interior-projection arcs {|r cos d - a| <= w, |r sin d| <= Q} and two endpoint arcs {r^2+1-2r cos(d -+ alpha) <= w^2}; arcs of all N rotated segments are merged exactly; U(r) = uncovered fraction; V_N = 2 int r U dr. U=1 for r < a-w. Fast path when all arcs have equal length (r<1-w): union length = sum min(L, circular gap of sorted starts); verified equal to the general merge (max |dU| 1.3e-14). Composite 6-point Gauss-Legendre, panel width h/N, breakpoints at a-w, a, a+w, Q, sqrt((a+-w)^2+Q^2), 1-w, 1.
- Also in geom.py: V(x,c) (limit), Vtilde_N (exact piecewise integral), brute segment-distance MC (open path, N+1 vertices).
- Commands (from `independent/`): `python3 validate.py` (-> results/indep-validation.json), `python3 experiments.py` (10 workers, 614 s; -> results/indep-experiments.{json,csv,stdout.log}), `python3 analyze.py` (-> results/indep-analysis.md, tables below). From repo root: `python3 circle_research.py --full --seed 777 --ns 4181 5574 --output results/indep-mc-seed777` (also seeds 778, 779 as extra).
- Experiment config/code hash/timings are in indep-experiments.json (config block).

## Validation
- (a) Per-segment arcs vs 400001-point brute angular sampling, 8 alphas (golden, pi/2, 2pi/5, 0.7pi, 0.3pi, 3pi/7, pi/3, 0.9pi), 60 random (r,w) each: 0 mismatching grid points everywhere.
- (b) Small N vs brute MC (2e6 pts), z = -1.44 (N=8), -0.89 (21), -0.87 (34,c=2), +0.74 (pi/2,N=12), -0.24 (2pi/5,N=15), +1.72 (0.7pi,N=17). Refinement diffs <= 1.6e-5 (the 0.7pi case, a<0, has no breakpoints at |a|+-w; others <= 3e-7).
  A first MC run showed z up to -51; cause was MY brute code closing the polygon (np.roll). Fixed to N+1 vertices; the exact integrator was not changed. The reference code uses n+1 vertices (correct).
- (c) N=4181, 5574 vs saved results/verified-full.json (seed 20261115): V_N (h=0.5) = 0.336056 / 0.338011 (c=1), 0.156116 / 0.161916 (c=2); h=1 vs h=0.5 differ <= 2.4e-6. z = +0.40, +0.73, +0.31, -0.03. Paired differences z = +0.41 (c=1), -0.62 (c=2).
- Alternate seeds (z of MC vs exact; n0, n1, paired diff): seed 777 c=1: -2.19, -0.91, +1.58; c=2: -0.64, +0.85, +2.69. seed 778 c=1: -0.65, -0.94, -0.37; c=2: -1.10, +0.08, +2.10. seed 779 c=1: -0.29, +0.02, +0.37; c=2: +0.48, +1.08, +1.10.
  Discrepancy to flag: the c=2 paired difference (N=5574 minus N=4181) is above exact in 3 of 4 MC runs (z 2.69, 2.10, 1.10; saved run -0.62; pooled ~ +2.6 sigma if independent). Exact diff is 0.005799. Not explained; may be chance or underestimated paired SE in the reference MC. Single-N values are all within 2.2 sigma. Worth more seeds.

## Findings
- Convergence: V_N - V(x,c) and V_N - Vtilde_N are both ~ -0.72/N at c=1 (log-log slope -0.93 to -1.01 across c in {0.5,1,2,3}, x in {0,1/3}, m=12..21). N*(V_N-V) ~ -0.71 for Fibonacci at c=1. At these N, Vtilde_N agrees with V(x,c) to 6 digits, so the O(1/N) gap is a finite-N effect of the tube model, not of the gap-statistics approximation. Consistent with V_N -> V; the limit is supported, rate O(1/N) (numerical fit, 10 points per series).
- Phase sweep: at m=20 and m=21, c=1 and 2, the minimum of V_N over the sampled block (17 / 15 x values in [0, lambda]) is at x=0 (Fibonacci). max |V_N - V(x,c)|: m=20 1.05e-4 (c=1), 2.13e-4 (c=2); m=21 6.7e-5, 1.3e-4; the gap is a smooth, nearly constant offset, so the shape in x matches. Note V(x,c) at m=20 is not minimized at x=0: V(0,c)=V(lambda,c) by block continuity (x=lambda is next Fibonacci), so the x=lambda endpoint ties; finite-N V_N at x=lambda (N=F_21=10946) is 0.156329 vs 0.156249 at x=0 (N=F_20), consistent with the -0.7/N offset, not a violation. Minimum "at x=0" is within the sampled grid and ties with the next block's x=0 by construction; argmin check is therefore only meaningful for interior x, where V_N exceeds the endpoints.
- Threshold (m=20): raw V_N - a^2 is negative for every c (about -2ac/N from the region r<a-w being counted at (a-w)^2 instead of a^2). After adding 2ac/N back, V_N - a^2 matches V(x,c) - a^2: c=4,x=0.55: 5.99e-5 vs 5.93e-5; c=4,x=0.6: 6.0e-6 vs 5.5e-6; c=5,x=0.55: 1.07e-6 vs 7.7e-7; c=5.4: 0 or ~1e-9 predicted (x=0.6 only) where finite-N residuals (~4e-7 and below) are below the finite-N noise. Fibonacci (x=0): adjusted +3.7e-7 (c=4), +5.6e-7 (c=5), vs predicted 0 (Q*pi*C < c there). Sign pattern V(x,c)>a^2 iff c < Q*pi*C*(1+x) (c*=5.547 at x=lambda) is consistent in sign for c=4 and 5 at x>0; for c>=5.4 the predicted excess is 1e-9 or less and is not resolvable at N~10^4 (differences of order 1e-7 are within the O(1/N) correction magnitude). Evidence for the threshold shape only, not for its exact location.

## Limitations
Double precision; no error bars on the integrator beyond h-refinement (about 1e-6 at N~4000, larger for a<0 case); h=1 used in experiments (not re-refined at N>5574); one tested value of x grid; Gauss-Legendre on an oscillatory (scale 1/N) integrand; MC comparisons are statistical. Numerical agreement is not proof.
